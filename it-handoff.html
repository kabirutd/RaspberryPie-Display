Detailed request for the IT ticket

Subject: Warehouse TV setup for Power BI reports

Hi IT team,

I’d like to use the warehouse TV to display our OTD Dashboard and Warehouse Management reports throughout the day. Since another monitor already has a Raspberry Pi setup, could we check whether the same setup would work here?

I’ll need help with the Pi and TV installation, network connection, automatic full-screen startup, sleep settings, and recovery after a restart or network interruption.

I develop and manage the Power BI reports. Once the device is ready, I’ll configure the report links, pages, filters, refresh mechanism, and rotation. Please show me whether this is a normal Pi desktop or a managed signage player. I’ll need the device name/address, an approved login, access to the actual TV desktop or player dashboard, and a walkthrough of opening the settings/terminal. Let’s make the first refresh change together and confirm how it starts after reboot.

For secure access, please help confirm the right display account or player, licensing, and sign-in policy with the relevant administrator. I can grant report access within my permissions. The reports need to stay private; please don’t use Publish to web.

I’d like to start with 60 seconds per report and a five-minute display reload where the player supports it. I’ll configure the data-refresh schedule separately. If the browser will need periodic sign-in, please let me know what to expect and how we’ll restore access.

Before handoff, let’s test startup, full screen, refresh and rotation, current data, network recovery, and recovery after a restart. I’ll also need the support contact, safe restart steps, and the approved way to update the configuration.

Thanks!

Remote-access request for IT

Please enable remote management of the warehouse Pi from my work laptop so I can maintain refresh without connecting a keyboard each time.

  • Provide an approved screen-sharing method that connects to the actual desktop displayed on the TV, rather than a separate session.
  • If we use Pi scripts, enable SSH with key-based authentication and give me the hostname/IP and approved account.
  • Allow access from my laptop through the company network or VPN.
  • Give me permission to edit the refresh/rotation configuration and use the agreed restart procedure.
  • Make sure remote access works again after a reboot.
  • Show me how to connect, change the refresh interval, restart the helper, and verify the result on the TV desktop.

If this is a managed signage player, please give me access to its management dashboard instead.

We’ll keep connection details in the private IT ticket. My remote-management workflow explains how I’ll use this access.
